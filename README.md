# Cupcake worm game
A grid based snake game built with Python tkinter. Control the worm to collect "cupcakes" and build up your high score.

# Features
Two types of controls; arrow keys and wasd
Power boost: Hold Down the Space Bar to get a powerboost
Restart the game with a restart button 
Score Tracking 
Collision system where touching the sides and touching the worms own body parts with result in game over

# What I learned
I followed a tutorial I found and I learned more about classes and objects to group coordinates to reuse them. I used bind to connect commands to keyboard keys. I also used the same logic for keypressspace and key release space. 
I used space size ot make predictable movement and alignment.
